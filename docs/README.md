# Docs Index

This `docs/` directory is the raw source layer for Stagecom.

The maintained synthesis layer lives in:

- `wiki/` for agent-first consultation

Workflow expectation:

- consult the wiki first for project understanding
- update `docs/` when the raw source of truth changes
- keep the wiki synchronized when `docs/` changes materially

Documentation is organized by subject:

- `product/` - product requirements, visibility policy, and event/notification behavior
- `development/` - workflow, coding rules, data-layer guidance, and server API conventions
- `data/` - data model and mock-data workflow
- `specs/` - feature specs organized by date in `YYYY-MM-DD/` folders
- `research/` - research snapshots and exploratory notes
- `sql/` - schema and seed SQL
