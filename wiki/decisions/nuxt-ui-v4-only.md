# Nuxt UI v4 As Sole Component Library

**Status:** current
**Last updated:** 2026-04-21
**Sources:** [[raw/development/coding-rules.md]], [[raw/design/app-design-bible.md]], [[raw/specs/2026-04-12/feature-spec-component-system-v1.md]]

## Decision

Nuxt UI v4 is the only approved component-library foundation for app UI.

## Reasoning

- The design system wants one coherent ownership hierarchy.
- Existing docs repeatedly reject introducing a second component library.
- App-specific primitives should be thin semantic layers, not a parallel base-component stack.
