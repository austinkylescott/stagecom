# Docs Index

Documentation is organized by subject:

- `product/` - product requirements, visibility policy, and event/notification behavior
- `development/` - workflow, coding rules, data-layer guidance, and server API conventions
- `data/` - data model and mock-data workflow
- `specs/` - feature specs
- `research/` - research snapshots and exploratory notes
- `sql/` - schema and seed SQL
